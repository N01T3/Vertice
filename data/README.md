# Dados

Esta pasta contém arquivos de entrada, bases de referência e exemplos usados pelo VÉRTICE.

## Estrutura

- `sinapi/`: bases SINAPI fornecidas para importação e validação.
- `examples/`: planilhas de referência e casos reais anonimizados para conferência.
- `archives/`: arquivos compactados recebidos ou mantidos como fonte original.

As bases não são carregadas automaticamente pelo sistema. O processo de importação deve registrar versão, hash, metadados, estado de validação e origem do arquivo.
